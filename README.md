Site Oficial — Escola Municipal Dom Bosco

Meu primeiro site profissional, desenvolvido e publicado para a Escola Municipal Dom Bosco (rede municipal de ensino de Belo Horizonte).

 Site no ar: emdombosco.com.br

 Sobre o projeto

Site institucional criado para centralizar a comunicação da escola com alunos, professores e famílias, substituindo avisos informais por um canal oficial e organizado.

 Funcionalidades
Publicação de avisos gerais para toda a escola
Publicação de avisos segmentados por turma
Estrutura de páginas institucionais do site
 
 Tecnologias utilizadas
HTML5
CSS3
JavaScript (criação e exibição dos avisos por turma/gerais)
